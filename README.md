# 🎂 BuddyWish — Telegram Birthday Bot

Telegram-бот для отслеживания дней рождения, поздравлений, праздников и личных событий.

---

## 🔥 Возможности

### 👤 Профиль
- Регистрация по дате рождения (дд.мм.гггг)
- Аватарка из Telegram (или дефолтная)
- Возраст и дни до следующего ДР

### 🔔 Отслеживание друзей
- Напоминания за 3, 2 и 1 день до дня рождения
- Поиск пользователей по @username
- Поделиться профилем через deep link

### 🎉 Поздравления
- Прямо из уведомления — кнопки поздравления
- 6 готовых шаблонов или своё поздравление
- Поздравление эмодзи (без текста)
- **Серия поздравлений** — считается сколько разных друзей подряд вы поздравили
- Рекорд серии сохраняется навсегда
- Милестоуны серии: 2 / 5 / 10 / 20 / 50 поздравлений подряд

### 🎁 Вишлист
- Список желаемых подарков
- Виден всем друзьям
- Добавление / удаление / очистка

### 🗓 Праздники
- Каталог 25+ популярных праздников с эмодзи
- Подписка / отписка одним нажатием
- Праздники отсортированы по ближайшей дате
- Напоминания заранее (за 1–7 дней в зависимости от праздника)

### ✨ Личные события
- Создание события с названием и датой (дд.мм или дд.мм.гггг)
- Ежегодный или одноразовый повтор
- Напоминание за 3 дня

### 📊 Личная статистика
- Кол-во отслеживаемых и отслеживающих
- Кол-во приглашённых друзей
- Всего поздравлений, текущая серия, рекорд
- Реферальная ссылка

### 🏅 Система титулов (по приглашениям)
| Приглашения | Титул |
|-------------|-------|
| 0 | 🌱 Новичок |
| 1 | 🤝 Первый шаг |
| 3 | ⭐ Активист |
| 5 | 🌟 Коннектор |
| 10 | 💫 Амбассадор |
| 20 | 🏆 Легенда |
| 50 | 👑 Гроссмейстер |

### 🛡 Админ-панель
- Рассылки с фото и текстом, настройкой периодичности и даты окончания
- Управление каналами (обязательная подписка)
- Статистика бота (пользователи, поздравления, рекорд серии и др.)
- Список всех пользователей с пагинацией

## 📁 Структура файлов

```
buddywish/
├── bot.py           # Точка входа
├── config.py        # Конфигурация из .env
├── database.py      # Все операции с SQLite (aiosqlite)
├── handlers.py      # Все хэндлеры aiogram
├── keyboards.py     # Reply и Inline клавиатуры
├── scheduler.py     # APScheduler: ДР, праздники, события, рассылки
├── holidays.py      # Каталог популярных праздников
├── utils.py         # Парсинг дат, возраст, дни до ДР
├── default_avatar.png  # Дефолтная аватарка (добавьте сами)
├── requirements.txt
├── .env.example
└── .env             # Ваши настройки (не коммитить!)
```

---

## 🚀 Установка

```bash
git clone <repo>
cd buddywish

pip install -r requirements.txt

cp .env.example .env
# Отредактируйте .env — укажите BOT_TOKEN и ADMIN_IDS

python bot.py
```

---

## ⚙️ Конфигурация (.env)

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_IDS` | Telegram ID администраторов через запятую |
| `DATABASE_PATH` | Путь к SQLite файлу (по умолчанию: `birthday_bot.db`) |

## 📌 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Регистрация / главное меню |

| `/search` | Найти пользователя по @username |
| `/friend` | Список отслеживаемых друзей |
| `/holidays` | Праздники и личные события |
| `/mystats` | Моя статистика |
| `/invite` | Реферальная ссылка + титулы |
| `/help` | Список всех команд |
| `/admin` | Панель администратора |

---

## 📝 Важные замечания

- **Аватарки**: бот получает фото только если пользователь не скрыл их в настройках приватности
- **Каналы**: бот должен быть **администратором** канала для проверки подписки
- **default_avatar.png**: добавьте картинку самостоятельно — она используется как дефолтная аватарка
- **Серия поздравлений**: считается по количеству разных людей, поздравленных подряд. Один человек = одно поздравление в год.
